# SeerGo 体育老师微课堂 · 75集按键指引版

面向体育老师的短视频培训资料，每集讲解一个功能，均少于一分钟。包含随步骤切换的橙色箭头和描边框。

## 获取和观看

1. 点击仓库上方 **Code → Download ZIP**，下载并解压全部资料。
2. 打开 `training-videos/观看目录.html`，可分类、搜索及播放视频。
3. 单集 MP4 位于 `training-videos/视频/`，可单独下载。

本仓库是私有资料库，尚未部署为在线培训网站。只有获得仓库访问权限的 GitHub 账号可以访问。GitHub 文件浏览页面不会直接运行 HTML 培训目录。
